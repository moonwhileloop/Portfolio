# PERSONAL PORTFOLIO

A responsive personal portfolio built using **Vanilla JavaScript, HTML5, and CSS3**. Designed to showcase my projects, technical skills and journey into software development.

## Key Features
- **Interactive 3-card project carousel:** custom Vanilla JS slider featuring central focus styling, 3D perspective scaling and depth-of-field blurring for inactive cards.
- **Custom Flat-Neon UI:** built entirely with pure CSS (flexbox, pseudo-elements, custom gradients, and smooth transitions) without relying on external CSS frameworks.
- **Working contact form:** integrated with Formspree for direct email messaging.

## Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Integrations:** Formspree (Contact Form)

## How to run locally
1. Clone the repository
   https://github.com/moonwhileloop/Portfolio.git
2. Open the folder in VS Code, simply double-click homepage.html to open it directly in your default web browser or right-click on homepage.html and select "Open with Live Server".
